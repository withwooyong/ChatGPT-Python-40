# 채트GPT로 만드는 파이썬 작품들

이 프로젝트는 ChatGPT를 활용하여 만든 다양한 파이썬 프로그램들의 모음입니다. 초보자부터 중급자까지 파이썬 프로그래밍을 학습하고 실습할 수 있는 40개의 다양한 프로젝트로 구성되어 있습니다.

- **22. MBTI 성격유형 검사프로그램 만들기** - 웹 기반 MBTI 검사 시스템

## 🛠️ 사용된 기술 스택

### 핵심 언어

- **Python 3.x** - 메인 프로그래밍 언어

### 주요 라이브러리

- **Flask** - 웹 프레임워크
- **SQLite** - 데이터베이스
- **pandas** - 데이터 분석
- **matplotlib** - 데이터 시각화
- **scikit-learn** - 머신러닝
- **pyupbit** - 암호화폐 API
- **qrcode** - QR 코드 생성
- **pyttsx3** - 텍스트 음성 변환
- **requests** - HTTP 요청
- **openpyxl** - 엑셀 파일 처리

### 외부 서비스

- **Upbit API** - 암호화폐 데이터
- **OpenWeather API** - 날씨 정보
- **Google Translate API** - 번역 서비스

## 🚀 시작하기

### 필수 요구사항

- Python 3.7 이상
- pip (Python 패키지 관리자)

### 설치 방법

1. 저장소 클론

```bash
git clone [repository-url]
cd 채트GPT로-만드는-파이썬-작품들_소스코드
```

2. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

3. 원하는 프로젝트 폴더로 이동하여 실행

```bash
cd "01.숫자 맞추기 게임 만들기"
python main1.py
```
